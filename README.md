Доставка грузов
Три груза (A, B, C кг) можно погрузить в контейнер, если вес каждого из них кратен пяти. 
Запишите условие, при котором диспетчерская система дает разрешение на погрузку.

**1. АЛГОРИТМ**
  1. Начало
  2. Ввод данных с клавиатуры (A,B,C)
  3. Проверка каждого значение на деление на 5 (A % 5 == 0 && B % 5 == 0 && C % 5 == 0)
  4. Если **ДА**:
     Вывести "Диспетчерская система дает разрешение на погрузку"
  5. Если **НЕТ**:
      Вывести "Диспетчерская система не дает разрешение на погрузку"
     
  6.Конец
